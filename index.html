Key safety
Your API keys are never part of the website's code. They are saved only in this browser on this device, and are sent directly to Anthropic, OpenAI or Perplexity when you generate content. Anyone who uses this browser profile could reach them, so avoid saving keys on shared or public computers, and set spending limits in each provider's dashboard. Treat your Google Apps Script URL like a password too: anyone who has it can read and write your Sheet.
Anthropic API key
Stored only in your browser's localStorage. Never sent anywhere except directly to Anthropic's API.

Used for image generation (gpt-image-1). Stored only in your browser's localStorage.
